# humanology_daily Shorts Factory v1.3

브라우저에서 실행하는 실제 쇼츠 카드 렌더러입니다.

## 사용법
1. `index.html`을 Chrome 또는 Edge로 엽니다.
2. OpenAI API Key를 입력하고 저장합니다.
3. 소재를 뽑거나 주제를 직접 넣습니다.
4. `대본 자동 생성`을 누릅니다.
5. 아래 `진짜 쇼츠 카드 렌더러`에서 1080×1920 실제 카드가 생성됩니다.
6. 카드별 미리보기 썸네일을 클릭해 확인합니다.
7. `현재 카드 PNG 저장`으로 개별 이미지를 저장할 수 있습니다.
8. `영상 녹화`를 누르면 브라우저가 지원하는 형식으로 영상이 저장됩니다. 일반적인 Chrome/Edge 환경에서는 WebM이 가장 안정적입니다.

## 보안 주의
현재 버전은 테스트 편의를 위해 브라우저에서 OpenAI API를 직접 호출합니다. 실제 공개 서비스로 배포할 때는 API 키를 브라우저에 넣지 말고 서버/서버리스 백엔드에서 API를 호출하도록 바꾸는 것을 권장합니다.
